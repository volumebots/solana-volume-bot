# Contributing

This repository accepts contributions to public documentation and media references. It does not accept or distribute bot source code.

## Useful Contributions

- Fixing broken official links
- Correcting spelling, grammar, or formatting
- Updating a product fact using a current official ChartUp source
- Clarifying responsible-use or security guidance
- Improving accessibility, including descriptive image text

## Requirements

1. Keep product claims factual and attributable to an official source.
2. Do not add guaranteed financial, ranking, or market-performance claims.
3. Do not describe simulated activity as genuine users or demand.
4. Do not add unofficial Telegram accounts, referral links, shortened URLs, or payment addresses.
5. Do not include secrets, credentials, personal information, or private support conversations.
6. Preserve the repository's clear statement that the production service is proprietary and not published here.

## Pull Requests

- Explain what changed and why.
- Link the official source supporting a product or policy update.
- Keep each pull request focused on one subject.
- Confirm that all local Markdown links and image paths work.

Submitting a contribution does not authorize use of ChartUp trademarks or proprietary service materials outside this repository.
