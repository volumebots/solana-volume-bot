# Support

## Official Support Channel

Contact [`@chartup_support`](https://t.me/chartup_support) on Telegram.

For documentation corrections relating only to this repository, open a GitHub issue using the documentation template.

## Before Contacting Support

Prepare the following non-sensitive information when relevant:

- Official bot username used
- Network and supported venue
- Public contract address
- Approximate task time
- Public transaction identifier or payment confirmation
- Clear description of the expected and observed behavior
- Screenshot with private information removed

## Never Send

- Private keys
- Seed phrases
- Telegram login codes
- Passwords
- Identity documents unless an official legal process specifically requires them
- Remote-control access to your device

## Scope of GitHub Issues

Appropriate public issues include broken links, typographical errors, outdated screenshots, unclear repository documentation, and verifiable inconsistencies between this repository and current official sources.

Billing, task delivery, eligibility, account access, legal questions, abuse reports, and security issues should be handled privately through official support.
