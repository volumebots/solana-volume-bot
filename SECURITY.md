# Security Policy

## Scope

This public repository contains documentation and media assets. It does not contain the hosted ChartUp bot, production infrastructure, private wallet systems, or proprietary execution code.

Security reports may still concern:

- An official ChartUp website, bot, or API
- Impersonation of ChartUp accounts
- A malicious or misleading link in this repository
- Accidental publication of confidential information
- A vulnerability that could affect user data or service operation

## Reporting a Security Issue

Do not open a public GitHub issue for a suspected vulnerability, leaked credential, payment-address concern, or active impersonation attempt.

Contact ChartUp privately:

- Telegram: [`@chartup_support`](https://t.me/chartup_support)
- Email: `support@chartup.io`

Include only the information needed to reproduce or verify the issue. Do not send private keys, seed phrases, passwords, identity documents, or unrestricted access tokens.

## Credential Safety

ChartUp representatives should never request:

- A wallet private key
- A seed phrase
- Remote access to a user's device
- A permanent wallet connection for the standard bot workflow

Stop communication and contact official support if anyone requests these items.

## Verify Official Accounts

Use links from the [official website](https://www.chartup.io/), [documentation](https://chartup.gitbook.io/docs), or [Linktree](https://linktr.ee/chartup_io). Do not rely on Telegram search results, forwarded messages, unsolicited direct messages, or paid advertisements alone.

## Response Expectations

ChartUp will review reports according to severity and available evidence. Submission does not guarantee a reward, public disclosure, a specific remediation timeline, or eligibility for any bounty program.
